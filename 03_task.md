# Модуль company.py

В модуле хранится список сотрудников компании:

```python
employees = [...]
```

Каждый сотрудник описывается словарем следующего вида:

```python
{
    "id": 1,
    "name": "Иван Петров",
    "department": "IT",
    "age": 28,
    "hire_year": 2021,
    "fire_year": None,
    "history": [
        {"year": 2023, "salary": 3900, "projects": 4},
        {"year": 2024, "salary": 4300, "projects": 5},
        {"year": 2025, "salary": 4700, "projects": 6},
        {"year": 2026, "salary": 5200, "projects": 7}
    ]
}
```

## Описание полей сотрудника

| Поле | Описание |
|--------|--------|
| id | Уникальный идентификатор сотрудника |
| name | Имя и фамилия сотрудника |
| department | Отдел сотрудника |
| age | Возраст сотрудника |
| hire_year | Год приема на работу |
| fire_year | Год увольнения или None, если сотрудник работает |

## История сотрудника

Поле `history` представляет собой список словарей.

Каждый словарь содержит информацию за отдельный год:

```python
{
    "year": 2026,
    "salary": 5200,
    "projects": 7
}
```

### Поля истории

| Поле | Описание |
|--------|--------|
| year | Год |
| salary | Зарплата сотрудника за данный год |
| projects | Количество выполненных проектов за данный год |
